# 智能课堂（Intelligent Classroom）· 软件系统设计 作业三

> 一个基于 **RBAC 权限矩阵** 的课堂聊天系统：登录 → 我的课堂 → 进入聊天室，
> 每个角色的功能按钮完全由数据库里的权限数据决定。
>
> 前端：HTML + CSS + JavaScript（无框架、无构建）　后端：Python FastAPI + PyMySQL　
> 数据库：OceanBase / MySQL

---

## 一、快速开始（一步）

**双击 `前后端代码\启动智慧课堂.bat`**

它会自动：检查数据库 2881（没起就拉起 OceanBase）→ 检查后端 8000（没起就启动）→
两个端口都通了以后，自动在浏览器打开登录页。

登录页右侧会**自动检测并显示数据库连接状态**（`127.0.0.1:2881`、10 张表、30 用户、90 条记录）。
绿点 = 已连通。

> 也可以手动分两步：`cd 前后端代码\backend` → `python app.py`，然后浏览器打开
> <http://127.0.0.1:8000/login.html>

## 三、系统做什么

```
登录 ──► 我的课堂（课程卡片，显示"我在本课的身份"）
              │
              ▼
        课程聊天室
   ┌────────────────────────────────┐
   │ 消息流：谁（什么角色）用哪个功能做了什么   │
   ├────────────────────────────────┤
   │ 输入框                          │
   │ [5.查看作业内容][7.发布作业]…    │ ← 按钮由权限数据生成
   └────────────────────────────────┘
```

**核心设计**：所有功能都是聊天室输入框旁的按钮，点一下 → 落库成一条聊天记录。
不同角色（教师/助教/学生）看到的按钮不一样，**由数据库三张表决定**：

```
class_member.role_id（我在这门课是谁）
        ↓ role_menu
   我能用的菜单（按钮）
        ↓ 前端渲染
   我看到的界面
        ↓ 点击 + 后端二次校验（越权 403）
   数据落库
```

## 四、数据库（10 张表）

| 表 | 作用 |
|---|---|
| `user` | 用户（含专业、年级） |
| `role` | 角色：授课教师 / 助教 / 学生 |
| `user_role` | 用户-角色（多对多，一人可多角色） |
| `menu` | 功能点（= 权限点），`menu_url` 指向前端页面锚点 |
| `role_menu` | **角色-菜单 = 权限矩阵本体** |
| `course` / `class_member` | 课程 / 课堂成员（**成员自带本课角色**） |
| `chat_room` / `chat_record` / `chat_room_record` | 聊天室 / 聊天记录 / 记录归属 |

详见 `ER关系图.png` 与 `sql/` 下的两份脚本。

## 六、在别的机器上跑起来

1. **建库**：依次执行 `sql/01_建库建表.sql`、`sql/02_初始化数据.sql`（OceanBase / MySQL 都行）
2. **改配置**：`前后端代码/backend/config.py` 里的 `DB`（主机、端口、账号、密码、库名）
3. **装依赖**：`pip install -r 前后端代码/backend/requirements.txt`
4. **启动**：`cd 前后端代码/backend` → `python app.py`
5. **打开**：<http://127.0.0.1:8000/login.html>

> 默认配置是本地 OceanBase：`127.0.0.1:2881`、用户 `root@sys`、空密码、库 `Intelligent_Classroom`。
> 换 MySQL 的话把 `port` 改成 `3306`、`user` 改成 `root` 即可。
